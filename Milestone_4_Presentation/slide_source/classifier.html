5 development and 3 blind participants, same dataset. Cross-validation: 76.5% accuracy, macro-F1 0.55.

We froze the model and tested it once on three new people. It scored about 80% accuracy. But always guessing Wake scores about 76%, because people in these recordings spend so much time awake. So macro-F1, which treats all stages fairly, is a better measure, and it shows real skill. Our model and a simpler logistic regression were close. Just separating wake from sleep worked much better, at about 92% near sleep. The cut-off for that test was chosen on development data, after we saw the default cut-off underperform, so that one result is not strictly blind.
